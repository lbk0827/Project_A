# Card Effects Glossary

카드와 상태 효과의 기준 설명을 정리한 문서입니다.

## 카드 사용 관련

| 키워드 | 효과 |
| --- | --- |
| 증발 | 턴 종료 시 이 카드가 핸드에 있다면 소멸한다. |
| 소멸 | 이 카드는 사용 시 소멸된 카드 영역으로 이동한다. |
| 사용불가 | 이 카드는 사용할 수 없다. |
| 유일 | 이 카드는 복제되지 않는다. |
| 보존 | 이 카드는 턴 종료 시 버려지지 않는다. |
| 회수 | 이 카드가 무덤으로 이동하면 핸드로 가져온다. 효과 발동 시 회수를 제거한다. |
| 종극 | 이 카드를 사용하면 턴을 종료한다. |
| 개전 | 이 카드는 전투 시작 시 뽑을 카드 더미 맨 위에 둔다. |
| 신속 | 이 카드는 적의 행동 카운트를 감소시키지 않는다. |
| 주도 | 턴 시작 시 50% 확률로 카드의 비용이 1 감소한다. 다른 카드를 사용하면 효과를 제거한다. |
| 천상 | 비용 2 이상인 카드를 사용하면 이 카드가 발동한다. |
| 연계 | 다른 전투원 카드를 사용하면 적힌 효과가 발동한다. |
| 연속 | 이전에 사용한 카드와 같은 속성의 카드를 사용하면 이 카드가 발동한다. |
| 감응 | 이 카드가 드로우되면 감응 효과가 발동한다. |
| 영감 | 능력으로 드로우되면 발동한다. |
| 망각 | 이 카드는 소멸되지 않으며, 대신 뽑을 카드 더미 맨 위로 이동한다. |
| 봉인된 금기 | 이 카드는 번뜩임, 복제, 제거가 불가능하다. 보스 처치 시 금기 카드로 변환된다. |

## 이로운 효과 관련

| 키워드 | 효과 |
| --- | --- |
| 분쇄 | 실드를 보유한 대상을 타격하면 피해량이 20% 증가한다. |
| 약점 공격 | 이 카드의 공격이 약점으로 적용된다. |
| 사냥개시 | 타게팅 공격 카드 사용 시 대상에게 추가 공격 70%를 가하고 사냥개시가 1 감소한다. 사냥개시 수만큼 추가 공격 피해량이 30% 증가한다. 최대 5중첩. |
| 사기 | 사기 수만큼 피해량이 20% 증가한다. |
| 금속화 | 능력으로 실드를 획득하면 무작위 적에게 방어 기반 피해 80%를 준다. |
| 반격 | 피해를 받으면 공격자에게 방어 기반 피해 100%를 준다. 공격을 실드로 완벽하게 막으면 공격자에게 방어 기반 피해 150%를 준다. 효과 발동 시 반격이 1 감소한다. |
| 협공 | 아군이 특정 조건을 만족하면 대상에게 추가 공격 피해를 준다. |
| 근면 | 몬스터 처치 시 행동 포인트 1, 드로우 1을 획득한다. 턴당 1회. |
| 계몽 | 에고 스킬 사용 시마다 드로우 1을 획득한다. |
| 집중 | 턴 시작 시 체력이 50% 미만이면 행동 포인트 1을 획득한다. |
| 면역 | 해로운 효과를 획득하지 않는다. 발동 시 스택이 1 감소한다. |
| 결정화 | 턴 종료 시 결정화 수만큼 최대 체력의 20%에 해당하는 고정 실드를 획득한다. |
| 결의 | 결의 수만큼 실드 획득량이 20 증가한다. |
| 피해 감소 | 받는 피해량이 30% 감소한다. 효과 발동 시 피해 감소가 1 감소한다. |
| 물결 | 물결이 3이면 행동 포인트 1을 획득하고 물결이 3 감소한다. |
| 저장 | 행동 포인트를 보존한다. 효과 발동 시 저장이 1 감소한다. |
| 회피 | 1타 피격 시 체력을 잃지 않는다. 효과 발동 시 회피가 1 감소한다. |
| 다음 턴 드로우 | 1턴 후 턴 시작 시 드로우 1을 획득한다. |
| 불굴 | 불굴 수만큼 받는 피해량이 20% 감소한다. |
| 탄력 | 아군이 추가 공격 시 치유 50%를 적용한다. 발동 시 탄력이 1 감소한다. 최대 2중첩. |
| 초재생 | 턴 시작 시 치유 300%를 적용한다. |
| 탐구심 | 이 카드의 피해량이 20% 증가한다. |
| 범람 | 턴 시작 시 물결 1을 획득한다. |

## 해로운 효과 관련

| 키워드 | 효과 |
| --- | --- |
| 표식 | 공격 카드 사용 시 추가 공격 100%를 가하고, 비용 X만큼 강인도 피해를 준 뒤 표식이 1 감소한다. |
| 취약 | 받는 피해량이 50% 증가한다. 효과 발동 시 취약이 1 감소한다. |
| 고통 각인 | 고통 획득 시 고통 2를 추가로 획득한다. |
| 잔불 | 격파 상태인 대상을 타격하거나 대상을 격파하면, 대상이 보유한 잔불 수만큼 피해량이 30% 증가한다. 효과 발동 시 잔불을 제거한다. 최대 5중첩. |
| 약화 | 피해량이 25% 감소한다. |
| 열정 약점 | 열정 카드에 약점 공격을 적용한다. |
| 고통 | 턴 종료 시 고통 수만큼 고정 지속 피해 50%를 준다. 효과 발동 시 고통이 1 감소한다. |
| 손상 | 실드 획득량이 50% 감소한다. 효과 발동 시 손상이 1 감소한다. |
| 감전 | 공격 카드 사용 시 대상에게 고정 피해 80%를 준다. 대상이 실드를 보유했다면 피해량이 50% 증가한다. |
| 응징 | 실드 획득 시 아군에게 고정 피해 200%를 준다. 효과 발동 시 응징이 1 감소한다. |
| 붕괴 | 카드의 획득, 번뜩임, 제거가 불가능해진다. 전투원 에고 스킬을 사용할 수 없다. |
