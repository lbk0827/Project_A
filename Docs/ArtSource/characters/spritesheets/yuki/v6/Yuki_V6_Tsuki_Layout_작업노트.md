# Yuki V6 Tsuki Layout 작업 노트

## 작업 목적

Yuki 스프라이트의 `Walk`와 `Run`이 자연스럽지 않은 이유를 다시 확인하기 위해 Tsuki 스프라이트 시트와 씬 매핑을 비교했습니다. 비교 결과, Yuki는 Tsuki와 프레임 수와 시트 구조가 달랐고, `Walk`가 Tsuki 기준의 Idle/Attack 영역을 섞어 쓰고 있었습니다.

## Tsuki 기준 구조

- 시트 크기: `724x2172`
- 셀 크기: `181x181`
- 그리드: `4열 x 12행`
- 총 프레임: `48`

Tsuki 씬의 주요 매핑은 다음과 같습니다.

- `Idle`: 0, 1, 2, 3, 4, 5
- `Attack`: 7, 8, 9, 10, 11, 14, 13
- `Run`: 16, 17, 18, 19, 20, 21
- `Hit`: 42, 43
- `Dead`: 43, 42, 44, 45, 46, 47

## 기존 Yuki 문제

- 기존 Yuki 시트는 `724x1629`, `4열 x 9행`, 총 `36프레임`이었습니다.
- Yuki의 `Walk`는 4, 5, 6, 7, 8, 9, 10을 사용했습니다.
- 이 범위는 Tsuki 구조 기준으로 Idle 보강 프레임과 Attack 프레임 일부를 섞는 위치입니다.
- 따라서 걷는 동작이 아니라 한쪽 발이 앞으로 고정된 전진/공격 자세처럼 보였습니다.

## V6 적용 내용

- Yuki 런타임 시트를 Tsuki와 동일한 `724x2172`, `4x12`, `48프레임` 구조로 확장했습니다.
- `Idle`, `Attack`, `Run`, `Hit`, `Dead`는 Tsuki 씬의 핵심 프레임 위치를 기준으로 맞췄습니다.
- Tsuki 씬에는 `Walk`가 없으므로, Yuki 전용 `Walk`는 빈 중간 영역인 24-30번 프레임에 분리 배치했습니다.
- `Walk`가 더 이상 Attack 영역과 겹치지 않게 되었습니다.

## 현재 Yuki 매핑

- `Idle`: 0, 1, 2, 3, 4, 5
- `Attack`: 7, 8, 9, 10, 11, 14, 13
- `Run`: 16, 17, 18, 19, 20, 21
- `Walk`: 24, 25, 26, 27, 28, 29, 30
- `Hit`: 42, 43
- `Dead`: 43, 42, 44, 45, 46, 47

## 검수 메모

- 프레임 수와 셀 좌표는 Tsuki와 동일해졌습니다.
- `Walk`와 `Attack` 프레임 영역이 분리되어, 이전처럼 걷기에서 공격 자세가 섞이는 문제를 줄였습니다.
- 기존 Yuki 원본에는 Tsuki만큼 풍부한 `Hit/Dead` 전환 프레임이 없으므로, 해당 동작은 향후 별도 생성/리터칭 대상입니다.
- 비교 검수 이미지는 `tsuki_yuki_layout_compare.png`입니다.
