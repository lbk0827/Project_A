# Yuki V9 오른발 선행 Run 재제작

## 문제

- 기존 Run은 Tsuki의 포즈 실루엣만 대략 반영하고 다리의 소유 관계를 유지하지 못했습니다.
- 특히 첫 프레임 16번에서 Tsuki는 오른발을 사용하지만 Yuki는 오른발 허벅지와 발의 연결이 의상 천에 가려져 반대 발처럼 보였습니다.
- V8에서 17번 스트랩만 이동한 보정은 Run 전체 위상을 바로잡지 못해 폐기했습니다.

## 재제작 기준

- Tsuki Run 16-21 프레임을 각각 독립적인 포즈 기준으로 사용했습니다.
- Codex 내장 이미지 생성으로 각 프레임을 별도 제작한 뒤 크로마키 배경을 제거했습니다.
- Yuki의 검은 허벅지 스트랩이 있는 다리를 오른쪽 다리로 고정했습니다.
- 16번: 오른발 접지/선행
- 17번: 왼발 접지, 오른발 후방
- 18번: 공중 교차
- 19번: 오른발 접지
- 20번: 왼발 접지, 오른발 후방
- 21번: 16번으로 연결되는 리셋 자세
- 얼굴, 웨이비 롱헤어, 파란색 의상, 검은 코르셋, 검, 신발 디자인을 동일하게 유지했습니다.

## 정규화

- 모든 프레임을 `181x181` 셀에 맞췄습니다.
- 기존 Yuki와 같은 세로 범위인 `y=4..178`을 사용하여 크기와 발 기준선을 통일했습니다.
- Run 외 프레임은 V7 원본의 RGBA 픽셀을 그대로 유지했습니다.
- Run 셀은 이전 프레임이 아래에 남지 않도록 `181x181` 영역 전체를 교체했습니다.
