# Yuki V5 Walk/Run 작업 노트

## 작업 목적

Yuki V2 스프라이트의 `Walk`와 `Run` 프레임에서 한쪽 발만 반복해서 앞으로 나가는 듯한 문제가 있었습니다. 이번 작업은 기존 캐릭터 외형과 씬 매핑을 유지하면서, 걷기와 달리기 프레임의 좌우 발 교대감을 보강하는 것을 목표로 했습니다.

## 적용 방식

- 전체 스프라이트 시트를 다시 생성하지 않고, `Walk`와 `Run` 전용 스트립을 별도로 생성했습니다.
- 스트립에서 `Walk` 7프레임, `Run` 8프레임을 추출했습니다.
- 추출한 프레임을 기존 `724x1629`, `4x9`, `181x181` 스프라이트 시트의 동일 인덱스에 합성했습니다.
- `Idle`, `Attack`, `Hit`, `Dead` 프레임은 기존 적용본을 유지했습니다.

## 교체된 프레임

- `Walk`: 4, 5, 6, 7, 8, 9, 10
- `Run`: 16, 17, 18, 19, 20, 21, 22, 23

## 검수 메모

- 이전 버전보다 Walk에서 한쪽 발만 앞으로 고정되는 느낌이 줄었습니다.
- Run은 셀 경계 잘림 없이 들어갔고, 기존보다 발 교대가 더 읽힙니다.
- 이미지 생성 기반 보정이므로 수작업 픽셀 애니메이션만큼 완벽한 보행 곡선은 아닙니다. 추가 품질 개선이 필요하면 Walk/Run만 픽셀 단위 리터칭하는 방식이 가장 안전합니다.
