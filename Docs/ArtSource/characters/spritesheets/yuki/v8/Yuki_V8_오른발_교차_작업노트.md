# Yuki V8 오른발 교차 보정

## 문제

- 기존 Run 17번 프레임은 앞쪽 접지 다리가 스트랩 없는 왼쪽 다리로 표현되었습니다.
- 오른쪽 다리를 구분하는 검은 허벅지 스트랩이 뒤쪽 다리에 남아 있어, 보폭은 커졌지만 오른발을 내딛는 동작으로 읽히지 않았습니다.

## 수정

- Run 17번에서 오른쪽 다리의 식별 표식인 허벅지 스트랩을 앞쪽 접지 다리로 옮겼습니다.
- 뒤쪽으로 접힌 왼쪽 다리에서는 스트랩을 제거했습니다.
- Run 20번은 기존의 왼발 접지 자세를 유지하여 17번 오른발 접지와 반대 위상이 되도록 했습니다.
- 얼굴, 머리카락, 상체, 무기, 다른 애니메이션 프레임은 변경하지 않았습니다.
- V7 시트와 RGBA 픽셀을 비교하여 변경 프레임이 17번 하나뿐임을 확인했습니다.

## 판독 기준

- 17번: 스트랩이 있는 오른쪽 다리가 화면 오른쪽 앞으로 접지
- 20번: 스트랩 없는 왼쪽 다리가 화면 오른쪽 앞으로 접지
- 두 접지 프레임 사이에서 앞발의 식별 표식이 바뀌므로 좌우 발 교차가 명확하게 보입니다.
