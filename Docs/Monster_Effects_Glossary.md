# Monster Effects Glossary

몬스터가 보유하거나 몬스터 행동으로 부여되는 효과의 기준 설명을 정리한 문서입니다.

## 몬스터가 가진 효과

| 키워드 | 효과 |
| --- | --- |
| 야생의 감 | 공격 외 카드를 사용하면 분노 1을 획득한다. 분노가 4 이상이면 즉시 강력한 공격을 사용한다. |
| 분노 | 피해량이 10% 증가한다. |
| 숨겨진 칼날 | 탐색 식별자가 있으면 이 몬스터를 타게팅할 수 없다. |
| 허기 | 피해량이 20% 증가한다. 피격 시 허기가 1 감소한다. |
| 분노 표출 | 턴 시작 시 허기를 3으로 변경한다. |
| 착란 유발 | 턴 시작 시 착란을 3으로 변경한다. |
| 착란 | 공격 카드 사용 시 핸드의 모든 카드 비용이 1 감소한다. 공격 외 카드 사용 시 핸드의 모든 카드 비용이 1 증가한다. 효과 발동 시 착란이 1 감소한다. |
| 갈증 | 받는 피해량이 10% 감소한다. 피격 시 갈증이 1 감소한다. |
| 비행 | 피격 시 비행이 1 감소한다. 비행 제거 시 기절한다. 턴 시작 시 비행을 초기값으로 변경한다. |
| 과보호 | 받는 피해량을 1로 변경한다. 피격 시 과보호가 1 감소한다. |
| 봉쇄 | 카드 사용 시 카드의 효과가 발동하지 않는다. 카드 사용 시 봉쇄를 제거한다. |
| 빙결 | 드로우한 턴에 이 카드를 사용할 수 없다. |
| 탐구 | 카드의 피해량이 20% 증가한다. |
| 가사 | 체력이 0이어도 사망하지 않는다. 회복을 받으면 부활하며, 보유한 이로운 효과를 유지한다. |
| 성장기 | n턴 후 주체 못할 식탐으로 이 몬스터가 변화한다. |
| 무한의 절망 | 직전에 사용한 카드가 같은 전투원의 카드이면 즉시 강력한 공격을 사용한다. |
| 무한의 촉수 | 직전에 사용한 카드가 같은 전투원의 카드이면 행동 카운트를 0으로 변경하고 추가 행동을 획득한다. 무한의 촉수 제거 시 강한 행동으로 변경한다. |
| 맹독 주머니 | 이 몬스터 사망 시 취약 2를 부여한다. n턴 후 맹독 주머니를 제거한다. |
| 상처 악화 | 턴 시작 시 핸드의 출혈 카드 비용이 1 증가한다. |
| 대모의 유산 | 이 몬스터 사망 시 대모의 축복 2장을 생성한다. |
| 불두꺼비 | 이 몬스터가 피해를 주면 전투원에게 화염 가스 1을 부여한다. |
| 조급함 | 턴 시작 시 사기 1을 획득한다. 격파 시 사기가 5 감소한다. |
| 변덕 | 공격 카드 사용 시 이로운 효과 행동으로 변경한다. 스킬 카드 사용 시 공격 행동으로 변경한다. 최대 체력이 70% 미만이면 공격 행동으로 변경한다. |
| 주시자 | 턴 시작 시 무덤의 출혈 카드 수만큼 1턴간 사기 3을 획득한다. |
| 소환술 | 턴 시작 시 글루미 비스트를 최대 2개체까지 소환한다. 소환 시 소환술이 1 감소한다. |
| 크리쳐 | 소환자가 사망하면 이 몬스터도 사망한다. |
| 야성 개방 | 야성이 2 이상 또는 5 이상이면 강한 공격 행동으로 변경한다. |
| 야성 | 야성 수에 따라 행동을 변경한다. |
| 불길한 손아귀 | 이 몬스터가 타격하면 드로우 1을 획득한다. 드로우한 카드가 상태이상 카드이면 즉시 긁어내리기를 사용한다. |
| 포자 폭발 | 이 몬스터 사망 시 뽑을 카드 더미에 출혈 2장을 생성한다. |
| 기분파 | 턴 시작 시 변심을 3으로 변경한다. |
| 변심 | 공격 카드 사용 시 행동을 변경한다. 효과 발동 시 변심이 1 감소한다. |
| 맹신 | 실드 제거 시 최대 체력의 20% 고정 피해를 준다. 모든 몬스터가 이 몬스터가 받은 피해의 100%만큼 고정 실드를 획득한다. |
| 가호 | 이 몬스터의 실드가 보존된다. |
| 망자의 강골 | 피격 시 단단함 1을 획득한다. |
| 단단함 | 받는 피해량이 10% 감소한다. 턴 종료 시 단단함을 제거한다. |
| 불타는 뿔 | 단단함이 3 이상이면 강한 행동으로 변경한다. |
| 축제 | 턴 시작 시 응원 4~6을 획득한다. |
| 응원 | 카드 사용 시 응원이 1 감소한다. 응원 제거 시 모든 몬스터가 사기 1을 획득한다. |
| 재 속의 부활 | 체력이 0이 되면 이 몬스터가 변화한다. |
| 불굴 저지 | 1턴간 최대 체력의 30% 이상 피해를 받으면 불굴을 제거한다. |
| 확장 신호 | 실드를 보유한 상태로 턴을 종료하면 1턴 후 타격 1회를 추가한다. |
| 맹렬한 압박 | 턴 종료 시 실드를 보유하고 있으면 사기 1을 획득한다. |
| 방패병 | 실드 제거 시 약한 공격 행동으로 변경한다. 턴 시작 시 방패병이 1 감소한다. |
| 근엄한 집행관 | 피격 시 분노 1을 획득한다. 분노가 5이면 강한 공격 행동으로 변경한다. |
| 신념의 결사대 | 최대 체력이 10% 이하이면 이 몬스터가 사기 5와 절대 무적 1을 획득한다. |
| 절대 무적 | 1턴간 체력을 잃지 않는다. |
| 단죄 | 단죄가 5이면 1턴 후 강한 공격 행동으로 변경한다. |
| 신의 규율 | 행동 후 카드 사용 시 단죄 1을 획득한다. 격파 시 신의 규율을 제거한다. 1턴 후 턴 시작 시 신의 규율 1을 획득한다. |
| 신앙심 | 턴 시작 시 단죄 1을 획득한다. |
| 깊은 신앙심 | 턴 시작 시 즉결 단죄 1을 획득한다. |
| 즉결 단죄 | 즉결 단죄가 5이면 즉시 강력한 공격 행동을 사용한다. |
| 즉결 신의 규율 | 행동 후 이 카드를 사용하면 즉결 단죄 1을 획득한다. 격파하거나 이 몬스터가 단죄의 주먹을 사용했다면 즉결 신의 규율을 제거한다. 1턴 후 턴 시작 시 즉결 신의 규율 1을 획득한다. |
| 위기감 | 1턴간 최대 체력의 n%가 감소하면 즉시 게거품 물기를 사용한다. |
| 물의 수호 | 아쿠아볼 수만큼 사기 1을 획득한다. |

## 해로운 효과

| 키워드 | 효과 |
| --- | --- |
| 미끄러움 | 카드 사용 시 무작위 카드 1장을 버린다. 효과 발동 시 미끄러움이 1 감소한다. |
| 형상 | 최대 체력이 20% 감소하면 기절한다. 다른 몬스터가 없으면 행동을 변경한다. |
| 뜯어 먹기 | 뜯어 먹기 수만큼 사기를 획득한다. 피격 시 뜯어 먹기가 1 감소한다. |
| 소각 신호 | 실드 제거 시 공격 행동으로 변경한다. n턴 후 강한 공격 행동으로 변경한다. |
| 끈적이는 점액 | 피해를 받으면 고정 실드 60%를 획득하고 끈적이는 점액이 1 감소한다. 턴 시작 시 끈적이는 점액을 초기값으로 변경한다. |
| 촉진 | 행동 카운트가 감소할 때 행동 카운트를 1 추가로 감소시킨다. |
| 다가오는 공포 | 피격 시 다가오는 공포가 1 감소한다. 제거 시 행동을 변경한다. |
| 강화 행동 | 행동하면 강력한 공격 행동을 추가하고 강화 행동을 제거한다. 1턴 후 턴 시작 시 강화 행동을 획득한다. |
| 추가 행동 | 계속 행동할 수 있다. 행동 시 추가 행동이 1 감소한다. |
| 영혼 공유 | 받는 피해량을 0으로 변경한다. 가장 왼쪽에 위치한 구울이면 영혼 공유를 제거한다. |
| 급속 | 행동 카운트가 n 감소한다. 최대 9중첩. |
| 둔화 | 행동 카운트가 1 증가한다. 최대 9중첩. |
| 독 바르기 | 턴 종료 전 행동 시 50% 확률로 추가 행동을 획득한다. |
| 허기의 괴성 | 턴 시작 시 허기를 1로 변경한다. |

## 희귀종 몬스터 효과

| 키워드 | 효과 |
| --- | --- |
| 감염된 | 턴 시작 시 핸드의 무작위 카드 2장에 독을 부여한다. 독이 부여된 카드를 사용하면 몬스터 공격력 100%의 피해를 받는다. 이 피해는 실드를 무시한다. |
| 잠재된 | 공포. 모든 카드를 버리고 셔플한 뒤, 뽑을 카드 더미에 불안 1장을 생성한다. |
| 공포심 | 불안 수만큼 타격 1회를 추가한다. 턴 시작 시 불안의 비용이 1 증가한다. |
| 강요하는 | 턴 시작 시 무작위 카드 1장을 발동한다. |
| 식탐의 | 매 턴마다 몬스터가 처음 피해를 받을 때 사용된 공격 카드를 흡수한다. 몬스터 사망 시 흡수된 카드를 핸드로 회수한다. |
| 타오르는 | 몬스터가 행동할 때 뽑을 카드 더미에 화상 카드 2장을 추가한다. |
| 무거운 | 턴 시작 시 핸드의 무작위 카드 2장의 비용이 1턴간 1 증가한다. |
| 공허의 추격자 | 턴 시작 시 사기 1을 획득한다. 단꿈 전용. |
| 결정의 | 전투 시작 시 결정화 3을 획득한다. |
| 취약의 | 몬스터가 행동할 때 취약 2를 부여한다. |
| 강인한 | 몬스터가 받는 강인도 피해가 20% 감소한다. |
| 약화의 | 몬스터가 행동할 때 약화 2를 부여한다. |
