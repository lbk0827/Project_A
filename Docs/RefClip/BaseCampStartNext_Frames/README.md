# BaseCampStartNext reference frames

Source video: `Docs/RefClip/BaseCampStartNext.MP4`

These frames were extracted while analyzing the Kazena-style base camp start and next-node transition flow.

- `video_frames/`: broad timeline samples across the clip.
- `video_frames_playback/`: denser playback samples around the base camp and route selection sequence.
- `video_frames_transition/`: focused samples around the node selection to battle transition.

Use these images as visual reference for the in-game `BattleMapOverlay`, mini map placement, right-side next-node cards, and same-screen transition pacing.
